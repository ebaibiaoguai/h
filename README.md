# 智慧充电系列项目 README
# 项目背景
在新能源汽车产业快速发展的背景下，充电桩基础设施的智能化、数字化管理需求日益迫切，传统充电场站管理存在设备监控不实时、运营效率低、用户体验不佳、数据管理分散等问题。为解决行业痛点，打造一体化的充电场站管理与用户服务体系，研发智慧充电系列项目，实现充电场站的智能化运营、设备远程监控、用户便捷充电以及运营数据的可视化管理，适配商业充电场站、社区充电站等多场景的运营管理需求。
# 项目目标 
技术目标：搭建基于 Java 后端、Vue 前端、H5 移动端的全栈技术架构，整合 MySQL、Redis、Nginx 等中间件，实现高可用、易部署的智慧充电管理系统，支持服务端编译、打包、部署全流程标准化。

功能目标：实现充电场站、充电桩设备的全生命周期管理，用户端充电导航、扫码充电，管理端数据监控、运营统计、权限管理等核心功能，打通 “设备 - 场站 - 用户 - 运营” 的全链路数据流转。

运营目标：提升充电场站的运营效率，降低人工管理成本，实现设备状态实时监控、故障快速预警，同时为用户提供便捷、高效的充电服务，提升用户体验。

部署目标：制定标准化的服务器部署流程，支持编译环境快速搭建、项目一键式启动与运维，适配 CentOS 服务器环境，满足生产环境的稳定运行要求。

# 核心功能
本项目分为管理端、H5 移动端、后端服务端三大模块，各模块协同实现智慧充电全流程管理，核心功能如下：
# 一、后端服务核心功能
作为项目底层支撑，提供所有业务的接口服务、数据处理、中间件交互能力，核心能力包括：

数据持久化与缓存：基于 MySQL 实现场站、设备、用户、订单等数据的持久化存储，Redis 实现高频数据缓存，提升接口响应速度。

接口服务提供：为管理端、H5 移动端提供 RESTful API 接口，涵盖场站管理、设备监控、用户管理、权限控制、数据统计等所有业务场景。

配置与环境适配：支持多环境配置（vm 环境等），实现服务端口自定义、JVM 参数调优，保证服务稳定运行。

日志与监控：记录服务运行日志，支持接口调用、服务异常等信息的追溯，为运维提供数据支撑。
# 二、管理端系统功能
面向充电场站运营管理员，提供 PC 端可视化管理界面，核心功能包括：

场站管理：实现充电场站的新增、编辑、删除，维护场站基本信息（地址、坐标、充电桩数量、功率等），支持场站状态管控。

设备管理：监控充电桩设备的实时状态（在线 / 离线、空闲 / 占用、故障），维护设备基本信息，支持设备故障预警与记录。

用户管理：管理平台用户信息，支持用户新增、权限分配、账号状态管控，区分管理员、操作员等不同角色。

系统管理：实现平台基础配置、角色权限管理、密码修改、日志查看等功能，保证平台的安全运营。

数据统计：对场站运营数据、充电订单数据、设备使用率等进行统计分析，为运营决策提供数据支持。
# 三、H5 移动端功能
面向新能源汽车用户，提供轻量化的 H5 端服务，适配手机等移动设备，核心功能包括：

附近场站查询：基于地理位置展示周边充电场站，显示场站名称、地址、充电桩数量、设备状态等信息，方便用户导航。

场站详情查看：查看单个场站的详细信息，包括充电桩类型（交流 / 直流）、功率、收费标准等，为用户充电选择提供参考。

充电导航：支持场站地理位置导航，快速定位目标充电场站。

个人中心：实现用户基本信息查看、充电记录查询等基础功能，提升用户使用体验。

# 技术架构
# 开发环境
后端：Java 1.8、Maven 3.6.3、Spring Boot（基于 RuoYi-Vue 脚手架）

前端：Node.js 16.17.0、NPM 8.15.0、Vue.js

移动端：H5（HBuild 编译）

中间件：MySQL（数据存储）、Redis 6.2.6（缓存）、Nginx（静态资源部署、反向代理）

服务器：CentOS 8、YUM 包管理

# 部署架构
编译服务器：完成 JDK、Maven、Node.js 等环境搭建，实现项目代码的编译、打包。

应用服务器：部署后端 Java Jar 包，通过自定义脚本实现服务的启动、停止、日志管理。

静态资源服务器：通过 Nginx 部署管理端 dist 包、H5 端静态资源，实现反向代理转发接口请求至后端服务。

数据层：MySQL 负责业务数据存储，Redis 负责高频数据缓存，提升系统性能。

# 快速部署
本项目提供标准化的服务器部署流程，涵盖编译环境准备、中间件部署、代码编译、项目部署全流程，详细部署步骤参考项目配套的《智慧充电系列部署文档》，核心部署步骤如下：

搭建编译服务器环境，安装并配置 JDK、Maven、Node.js；

部署 MySQL、Redis 中间件，完成用户授权、密码配置等操作；

对项目后端、管理端代码进行编译打包，H5 端使用 HBuild 预编译包；

恢复项目数据库，部署后端 Jar 包并编写启动脚本，实现服务后台运行；

安装 Nginx，配置静态资源路径与接口反向代理，部署管理端和 H5 端静态资源；

启动所有服务，通过公网 IP 访问测试管理端（8000 端口）和 H5 移动端（80 端口）。

# 访问方式
管理端：通过浏览器访问 http://服务器公网IP:8000，使用管理员账号登录系统进行运营管理；

H5 移动端：通过手机 / 浏览器访问 http://服务器公网IP，即可查看附近场站、进行充电导航等操作。
